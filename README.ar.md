اسأل عن ملف PDF الذي تقرؤه. كل جواب يدلّك على الجمل التي أُخذ منها، وتراها
مظلَّلة في الملف.

**القراءة لك.** تعيدك Konnash إلى النص، ولا تقرأ بدلًا عنك.

**لكل قولٍ موضعه.** يستشهد الجواب بجمل بعينها، وما جاء بلا استشهاد يُعلَّم.

## التثبيت

1. حمّل الملف `konnash.xpi`.
2. في زوتيرو 10: Tools ← Plugins ← ⚙ ← Install Plugin From File…
3. من الإعدادات ← Konnash: اختر المزوّد وأضف مفتاحك (أحضر مفتاحك الخاص).

ثم افتح ملف PDF وانقر أيقونة Konnash في العمود الجانبي للقارئ.

قبل أن ترسل وثيقةً إلى خدمة ذكاء اصطناعي، تحقّق أن ترخيصها يسمح بذلك.
