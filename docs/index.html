Install

  1. Download konnash.xpi with the button above.
  2. In Zotero: Tools → Plugins → ⚙ → Install Plugin From File…
  3. Settings → Konnash: choose a provider and add your key.

Then open a PDF and click the Konnash icon in the side column.

التثبيت

  1. حمّل الملف konnash.xpi بالزر أعلاه.
  2. في زوتيرو: Tools ← Plugins ← ⚙ ← Install Plugin From File…
  3. من الإعدادات ← Konnash: اختر المزوّد وأضف مفتاحك.

ثم افتح ملف PDF وانقر أيقونة Konnash في العمود الجانبي.
